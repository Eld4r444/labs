# Лабораторная работа №1. Ответы к заданиям

- **Задание 5.** После `git switch main` файла `experiment.txt` нет: он закоммичен только в ветке `experiment`. При переключении Git приводит рабочий каталог к состоянию последнего коммита ветки `main`, а там этого файла ещё нет.
- **Задание 6.** После `git merge experiment` файл появился в `main`. Слияние прошло перемоткой (fast-forward), потому что `main` не менялась после создания ветки.
- **Задание 7.** `git restore notes.txt` вернул файл к состоянию последнего коммита, `git status` показывает чистый рабочий каталог.
- **Задание 8.** Нет, само изменение не удалилось. `git restore --staged` убирает его только из индекса, а в рабочем каталоге файл остаётся изменённым (`git status` показывает его как modified, но not staged).
- **Задание 9.** Нет, отменённый коммит остался в истории. `git revert` создаёт новый коммит `Revert "Экспериментальное изменение"`, который отменяет изменения, а исходный коммит сохраняется.
- **Задание 10.** Создана ветка `todo-list`, в ней два коммита с файлом `todo.txt`, разница показана через `git diff HEAD~1 HEAD`, ветка слита в `main`.

## Файлы
- `commands.sh` — все команды по порядку.
- `output.txt` — реальный вывод этих команд.
- `git_lab/` — итоговые файлы репозитория.
- `git_lab.bundle` — сам репозиторий со всей историей. Восстановить: `git clone git_lab.bundle git_lab`.
